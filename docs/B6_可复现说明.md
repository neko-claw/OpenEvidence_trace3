# B6：透明版本与可复现流程

本页定义赛道 3 的 B6 交付。B6 不改变 B1 的实验协议，也不把样例结果包装为正式实验结论；它负责把协议、输入、命令和输出连接为可检查的结果包。

## 两种结果等级

| 等级 | 用途 | 是否可作为正式结论 |
|---|---|---|
| `offline-reference` | 固定 fixture、无网络、无 API 的链路验收 | 否 |
| `formal-frozen` | B1/B2 已确认题集、gold、模型、配置和版本后的正式运行 | 是 |

当前仓库的冻结清单是 `repro/releases/track3-system-v0.2.lock.json`，状态为 `offline-reference`。它锁定 B1 协议、Schema、配置、依赖清单、预注册规则和离线 fixture 的 SHA-256；结果包还会记录实际 Python 与已安装包版本。正式题不足 60、STRESS 不足 20 或 gold 未齐全时，检查会保持“待冻结”。

## 命令

```bash
# 建议使用固定的 B6 依赖集合（Python 3.10–3.12）
python -m pip install -r repro/requirements.lock

# 只检查协议、配置、fixture 是否与冻结清单一致，并显示正式实验前置条件
python -m evaluation.reproduce --check

# 无 API key 的完整离线验收：C/D/E fixture 运行、Run Schema 校验、B5 报告重建
python -m evaluation.reproduce --offline-reference

# 校验既有结果包是否被改动；不会调用模型
python -m evaluation.reproduce --replay artifacts/b6/<release-id>/<time>

# 打开透明浏览页（不需要 API key）
streamlit run app.py
```

离线命令会生成 `artifacts/b6/<release-id>/<time>/`：

- `inputs/`：冻结时的协议、Schema、配置和 fixture 快照；
- `runs.jsonl`、`validation.json`：原始 Run 与 Schema 校验结果；
- `b5/`：由原始 Run 重建的统计文件和图表；
- `manifest.json`：精确命令、运行环境、代码提交和结果说明；
- `integrity.json`：结果包每个文件的 SHA-256。

## 展示边界

Streamlit 的“透明复现”页只显示冻结状态、正式运行前置条件、结果包完整性和单题轨迹。它不会加载 LLM、不会读取 API key，也不会把离线 fixture 的结果解释成医疗结论或正式模型比较。

云端模型即使固定模型名和参数，也可能随提供方更新而变化。因此正式运行应称为“可追溯重跑”，而只有本地固定 fixture 的链路可以进行确定性验收。
